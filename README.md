# 📱 Daily Task Manager - Android App

A clean, intuitive, and feature-rich native Android application designed to help users track, organize, and manage their daily tasks efficiently. Built with **Java**, **XML**, and **Room SQLite Database**.

---

## ✨ Features

- **Task Creation:** Add new tasks with details including Title, Description, Date, Time, and Priority level (Low, Medium, High).
- **Interactive Pickers:** Built-in DatePicker and TimePicker dialogs for seamless date/time selection.
- **Dynamic Task Filtering:** Instantly filter tasks by status:
  - 📋 **ALL:** Displays every created task.
  - ⏳ **PENDING:** Shows incomplete/active tasks.
  - ✅ **DONE:** Displays completed tasks.
- **Real-Time Status Toggle:** Interactive Checkboxes to mark tasks as completed or pending on the fly.
- **Local Persistence:** All task data is securely stored offline using Room Database.

---

## 🛠️ Tech Stack & Architecture

- **Language:** Java
- **UI Design:** Custom XML Layouts, Material Design Components
- **Database:** Room Persistence Library (SQLite)
- **IDE:** Android Studio
- **Min SDK:** API 24+ (Android 7.0)
